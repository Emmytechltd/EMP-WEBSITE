## 🆘 Common Questions

**Q: How do I add a new member?**
A: Open `members.html`, copy a member card, change the info.

**Q: How do I add more gallery images?**
A: Add images to `assets/images/gallery/`, update `js/script.js`.

**Q: Can I change the colors?**
A: Yes! Edit `css/styles.css` lines 13-17. Use htmlcolorcodes.com for color codes.

**Q: Why don't forms send emails?**
A: Default form shows confirmation. To send emails, use Formspree or EmailJS (see CUSTOMIZATION_GUIDE.md).

**Q: Can I add more pages?**
A: Yes! Copy an existing HTML file, rename it, update the navigation links.
