## 📞 Support & Troubleshooting

### Problem: Images not showing
**Solution:** Check file paths in `js/script.js`

### Problem: Contact form not working
**Solution:** Check if JavaScript enabled, look in console (F12)

### Problem: Mobile menu not opening
**Solution:** Check hamburger HTML, enable JavaScript

### Problem: Styles look wrong
**Solution:** Hard refresh (Ctrl+F5), clear cache

### Problem: Can't find something
**Solution:** Use Ctrl+F to search in documentation
