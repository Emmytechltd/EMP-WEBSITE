🎓 EMP 2015 Set Alumni Website

Modern, Responsive, Professional Alumni Community Platform

📋 Project Overview

A complete alumni website for the Educational Management and Policy (EMP) 2015 Set of Nnamdi Azikiwe University, Awka (Umunze Branch). This is a fully functional, modern web platform featuring responsive design, smooth animations, dynamic galleries, and comprehensive alumni management.

🚀 Getting Started

1. Quick Start (5 minutes)

  1. Extract all files to a folder
  2. Open index.html in your web browser
  3. Navigate through the pages to explore

2. Customize (30 minutes)

  1. Update contact information in contact.html
  2. Replace social media links throughout the site
  3. Add gallery images to assets/images/gallery/
  4. Update member profiles in members.html

3. Deploy (Varies)

  1. Upload files to your web hosting via FTP
  2. Point your domain to the hosting server
  3. Set up SSL certificate for HTTPS
  4. Test on multiple devices
